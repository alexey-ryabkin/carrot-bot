- Накопление группы сообщений.
- Запись сообщений в базу Маркова раз в 30 секунд при наличии.
- Небольшой шанс отправить сообщение в любой чат в любое время, прямо пропорциональный числу сообщений в чате за последнюю неделю и прямо пропорциональный времени молчания с последнего сообщения, прямо пропорциональный числу сообщений с последнего сообщения бота
- Отправляемое сообщение состоит из генерации Маркова. Определение шанса происходит независимо для каждого чата в памяти бота, генерируемый пользователь определяется случайно пропорционально числу сообщений каждого пользователя за последнюю неделю, но с минимальным шансом для всех участников чата
- Возможность пополнять бд заданной историей сообщений - запустить приложение с аргументом - путём к json экспорта сообщений.
